# Three-minute demonstration

All times are presentation timestamps, not claimed travel times.

| Time | Action |
|---|---|
| 0:00–0:15 | Explain that conventional routing optimizes time while RAHAT compares environmental exposure too. Point to the DEMO DATA label. |
| 0:15–0:40 | Show synthetic Hinjewadi junctions 12 to 17, 14:00 IST, delivery rider. |
| 0:40–1:00 | Compare fastest, thermal-safe, and balanced. Show actual computed differences; do not promise three distinct geometries. |
| 1:00–1:25 | Switch to 3D, move the departure slider, and show recalculated sunlight, shadows, and route metrics. |
| 1:25–1:45 | Start a simulated trip, pause it, and show accumulated exposure and its exact contribution breakdown. |
| 1:45–2:00 | Click I NEED RAHAT. The trip pauses while relief is ranked. |
| 2:00–2:20 | Inspect water, shade, cooling, distance, and actual additional travel time. |
| 2:20–2:40 | Select an eligible relief detour. Show whether geometry changed and review time/exposure differences. Resume. |
| 2:40–2:55 | Open Evidence and show source limitations and actual logical-agent execution timings. |
| 2:55–3:00 | Close: RAHAT AI does not simply navigate through a city; it compares ways through its heat. |

If a relief detour exceeds the configured allowance, show the real validation
message rather than claiming the reroute succeeded. Increase the allowance in the
planner only with an explicit user decision.

Simulation is accelerated: one complete road segment per tick. It is not GPS
tracking, turn-by-turn guidance, or a real-time navigation demo.
